# Troubleshooting

## Connection says No files location

Open **Settings** and enter **Files location**: the HTTPS address of the
folder holding Ginnie Mae's files.

## Connection says Not answering

The location refused or did not answer. The error beside it names the
address asked and why. Check the address and, if the location asks for one,
the token. A file the location does not hold is never an error: it is taken
as not published yet.

## A pool is declined source silent

None of the last thirteen months' factor files names the pool: check the
location holds Ginnie Mae's monthly files under their own names, and that the
record's pool number is right.

## A pool is declined not covered

The record asked for is not a Ginnie Mae pool or tranche, or its pool number
meets two records in the deployment (the Instruments page lists the conflict
to merge).
